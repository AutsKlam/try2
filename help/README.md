# 仓库帮助夹

用这个文件夹配合 Cursor Agent 管本仓库：复制短指令、看版本差异、维护每版备注。

| 文件 | 用途 |
|------|------|
| [指令卡.md](指令卡.md) | 复制到对话里直接发送 |
| [版本备注.md](版本备注.md) | 各提交的说明与人工备注 |
| [需求分析.md](需求分析.md) | 这套流程为什么这样设计 |

Agent 对应技能：`.cursor/skills/git-repo-ops/`（只在本机；`git更新` 默认不上传 `.cursor/`）。

## 怎么用

1. 日常上传最新版：对话里只发 `git更新`（或 `git更新 备注：…`）。
2. 查看可回退版本发 `历史版本`；撤回到某版发 `版本撤回 <哈希>`（新提交，不改写历史）。
3. 其它操作打开 `指令卡.md`，复制「发送」栏原文贴到对话。
4. 单独补某次提交的说明时，用「备注」类指令；Agent 只改 `版本备注.md`，不改 git 历史（`git更新` / `版本撤回` 除外，会 commit 并 push）。
