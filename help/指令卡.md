# 指令卡

用途：**备份 + 记修改时间**。对话里只发中文指令；Agent 会转成下面脚本。

| 发送 | 实际执行 |
|------|----------|
| `git更新` | `bash help/scripts/git-update.sh` |
| `git更新 备注：一句话` | `bash help/scripts/git-update.sh '一句话'` |
| `历史版本` | `bash help/scripts/history.sh` |
| `版本撤回 <哈希>` | `bash help/scripts/revert.sh <哈希>` |

默认不上传 `.cursor/`。分叉自动 rebase，仅冲突才停。

## 示例

```
git更新
```

```
历史版本
```

```
版本撤回 5d65867
```
