# 指令卡

本仓库用途：**备份各版本 + 记录修改时间与摘要**。日常只发下面三条。

| 发送 | 做什么 |
|------|--------|
| `git更新` | 备份当前改动：记时间与摘要 → 提交 → 推送 |
| `git更新 备注：一句话` | 同上，备注用你写的话 |
| `历史版本` | 列出已备份版本（哈希、时间、说明） |
| `版本撤回 <哈希>` | 用新备份恢复到该版（不改写历史） |

`git 更新` 与 `git更新` 相同。默认不上传 `.cursor/`。

Agent 收到后**直接执行**，不为分叉、选文件等再问你（仅冲突或无法解析哈希时停下）。

## 示例

```
git更新
```

```
历史版本
```

```
版本撤回 ce17d2b
```
