# 指令卡

复制「发送」整行到 Agent 对话。可把尖括号里的内容换成真实哈希、文件名或备注原文。

## 状态与差异

| 名 | 发送 |
|----|------|
| 状态 | 仓库状态 |
| 工作区改动 | 看未提交改动 |
| 暂存改动 | 看已暂存改动 |
| 最近提交 | 看最近 10 条提交 |
| 对比两版 | 对比版本 `<旧>` 和 `<新>` |
| 某文件历史 | 看文件 `<路径>` 的版本改动 |
| 本地相对远程 | 看本地和 origin 差在哪 |
| 某次提交详情 | 看提交 `<哈希>` 改了什么 |

## 备注

| 名 | 发送 |
|----|------|
| 同步备注 | 按 git 历史同步版本备注 |
| 给某版写备注 | 给版本 `<哈希或说明>` 备注：`<你的话>` |
| 改某版备注 | 更新版本 `<哈希>` 的备注为：`<你的话>` |
| 列出备注 | 列出各版本备注 |

## 快捷更新（一条完成提交 + 备注 + 推送）

只发下面这一行即可。有话要记时加上备注。

| 名 | 发送 |
|----|------|
| 更新并上传 | git更新 |
| 更新并写自己的备注 | git更新 备注：`<一句话>` |

`git 更新`（中间有空格）与 `git更新` 相同。默认不上传 `.cursor/`（Skill 只留在本机）。

Agent 会：归纳当前改动 → 写入 `版本备注.md`（更新时间 + 简要修改）→ commit → push。本地与远程分叉时会先停下，不会强推。

## 提交与同步（会改仓库，需你主动发）

| 名 | 发送 |
|----|------|
| 暂存指定文件 | 暂存 `<路径>` |
| 提交 | 提交，说明：`<一句话原因>` |
| 提交并写备注 | 提交并写入版本备注，说明：`<一句话原因>`；备注：`<可选>` |
| 对齐远程 | 先说明本地和远程怎么分叉，再按安全方式对齐 |
| 推送 | 推送到 origin |
| 拉远程 | 拉取 origin |

## 分支与 GitHub

| 名 | 发送 |
|----|------|
| 新分支 | 从 main 建分支 `<名>` 并切过去 |
| 开 PR | 把当前分支推上去并开 PR，标题：`<标题>` |

## 组合示例

上传当前工作为最新版本：

```
git更新
```

上传并自己写一句备注：

```
git更新 备注：修正 try222 输出文案
```

把暂存的 `try222.c` 交进去并记备注（不推送）：

```
提交并写入版本备注，说明：更新 try222.c 内容；备注：本地试验改动
```

先看清分叉再决定怎么合：

```
看本地和 origin 差在哪
```
